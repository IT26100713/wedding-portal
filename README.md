# wedding-portal
# Wedding Planning and Vendor Booking System

A web-based system designed to help users plan wedding events and manage
wedding-related services in one place.

## Project Overview

This project is developed as a group project. It brings together
different modules to support the wedding planning process.

## Project Modules

The system is divided into six main modules:

1.  **User Management** -- manages user accounts and user-related
    information.
2.  **Vendor Management** -- allows vendors to register and manage their
    profiles and service packages.
3.  **Booking Management** -- handles bookings between users and service
    providers.
4.  **Event Planning** -- supports the organisation and planning of
    wedding events.
5.  **Admin Management** -- provides administration of the system.
6.  **Review and Feedback** -- allows users to provide feedback about
    services.

## Technologies Used

-   Java
-   Spring Boot
-   HTML and CSS
-   Thymeleaf
-   MySQL
-   Git and GitHub

*Note: This is a conceptual module structure. The actual folder

## Main Objectives

-   Provide a central place to manage wedding-related services.
-   Organise the main wedding planning activities.
-   Support communication between users and vendors through the system.
-   Store and manage system information using a database.
-   Apply Object-Oriented Programming concepts in the Java application.

## How to Run the Project

1.  Install the required Java Development Kit (JDK).
2.  Install IntelliJ IDEA or another Java IDE.
3.  Install and start MySQL.
4.  Open the project in the IDE.
5.  Configure the database connection in `application.properties`.
6.  Run the main Spring Boot application.
7.  Open the local website URL shown in the application console.

*The exact database setup and run instructions may vary depending on the
final project configuration.*

## Team Project

This is a collaborative university project. Each group member is
responsible for developing an assigned module and integrating it into
the complete system.
